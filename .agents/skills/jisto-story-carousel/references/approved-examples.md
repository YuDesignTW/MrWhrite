## OXO｜用一個奇怪的物件帶出故事

封面：「賣削皮器，怎麼連紅蘿蔔都擺出來了？」

6 頁：店裡的紅蘿蔔 → 太太使用削皮器的困難 → 握柄開發 → 吸引人觸摸的細片 → 現場試削 → 回到買之前如何知道差別。

學習重點：由真實銷售細節帶入設計，觀點留到事件交代清楚之後。最後沒有另加三個教訓或一張強迫互動卡。

## IKEA IMPALA｜讓故事保留不漂亮的後半段

封面：「他贏了老闆一瓶酒。椅子卻沒留下來。」

6 頁：賭贏卻退場 → 老闆預期最多五件 → 設計師贏酒 → 製造複雜昂貴、一年退出 → 型錄低價與製造成本並列 → 後來的 BILLY 書櫃。

學習重點：有兩次真實轉折，不硬寫成設計師打臉老闆的勵志故事。「價格低」與「成本高」有來源，但沒有據此捏造毛利或虧損。

查看 [IKEA 整組縮圖](ikea-overview.jpg)。完整稿見 JSON 的 `02-ikea`。

## Mailchimp｜先讓讀者認識人，再看到大數字

封面：「他媽媽的美髮店，開在家裡的廚房。」

7 頁：母親的美髮生意 → 家族生意的挫折 → 設計公司副業 → 小店的工具需求 → 產品延伸 → 二十年的收購時間線 → 回到創辦人對家人生意的提問。

學習重點：家庭照片與人物故事讓「小企業」有具體樣貌。收購價放進時間，不暗示一夕成功；結尾回到原本的人與問題。

查看 [Mailchimp 整組縮圖](mailchimp-overview.jpg)。完整稿見 JSON 的 `03-mailchimp`。
