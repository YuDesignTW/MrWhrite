# 分發範圍

本資料夾是獨立的系統快照，不包含來源工作區的 Git 歷史。本機原工作區與資料未搬移或刪除。

保留通用前後端、Agent／Skills、工作流程、資料保護、測試、建置及本機啟動工具。移除組織專屬 Skill 與參考圖、舊文章與素材、實際追蹤資料、開發對話紀錄、歷史驗收產物及只服務舊資料的自動匯入邏輯。品牌預設改為通用文字；首個專案不包含既有組織的定位。

素材庫初始為空。舊素材庫測試改由 temporary directory 注入合成資料；流程契約測試使用新寫的合成研究、文案與帳號。內建九張背景是程式產生的幾何佔位圖，保留 renderer 檔名契約。

`.gitignore` 排除執行期資料、作品、輸出、環境設定及常見憑證檔。它不會清理遠端既有歷史，也不能替代對後續新增資料的檢查。

若推到已有歷史的倉庫，這份快照不會自動移除該倉庫以前的內容。此整理不包含 force-push、刪除遠端分支或改寫歷史。

第三方依賴與 Skills 的原始授權應保留；本專案沒有在此整理中代替作者選定新的開源授權。
