## 使用入口

本機服務：http://127.0.0.1:4389 。上方「創作工作台」進入；已加入三個作品，每篇包含完整文章、Threads 文案、IG 文案與六頁輪播。原本文章仍保留。

1. 觀點企劃：填受眾、觀察、本人觀點、假設、分享理由、下一步，可關聯最多三份情報。修改即暫存在本瀏覽器，按「儲存作品」才保存到後端。
2. 平台文案：可編輯、複製或下載；「從主稿擬文案」將必要上下文放入既有 AI 編輯流程。複製不會標為發布。
3. AI：產出後先看原文／建議，再接受或放棄。生成期間可以繼續寫，舊版本結果不可覆蓋新稿。真實生成目前仍受環境阻擋。
4. 輪播：4～8 頁、文字與版型可改、可排序；可加入自己的 PNG／JPEG，調上下裁切、填來源使用權。預覽與匯出共用同一渲染器，文字過多會阻擋輸出。
5. AI 輪播大綱：到寫作空間產出並接受 JSON 大綱，再回作品點「套用已確認的大綱」。格式錯誤不覆蓋輪播，前一版可還原。
6. 匯出：ZIP 包含順序 PNG、三份文案與 manifest；作品 JSON 備份含企劃、文章版本、發布與成效。全庫恢復仍用設定中的既有備份，作品 JSON 目前供攜出而非一鍵還原。
7. 發布與回顧：本人在平台發出後回填帳號、時間、選填連結；再選發布紀錄回填觀察時刻。未知數據留白，不填零；累積快照不相加。
8. 填寫下一輪決策，建立後續企劃。已排程的官方 Threads 流程繼續在寫作空間預覽確認，人工發布紀錄不會呼叫平台。
9. 版本衝突可「備份作品」或「另存作品」。作品與上次功能頁會記住；本地快記不是跨裝置同步。

## 本機 Codex 路線確認（同日追加）

使用者確認 AI 使用本機已登入的 Codex。呼叫鏈為本機介面 → Express → Codex CLI `exec` → 模型服務；沿用 CLI 登入，不新增 API Key 欄位。這是本機整合，並非離線模型推論。

這次修正 `.env` 的 MR_WHITE_CODEX 路徑延遲解析、登入檢查與生成環境白名單一致、UTF-8 串流與最後一行解析、逾時終止保底。介面將「已就緒」更正為「已登入」。錯誤分類不再被無關的 PATH alias 警告誤導。

實際重現的致命錯誤是 `failed to initialize in-process app-server client: Operation not permitted`，所以先前「禁止啟動子程序」應更正為「Codex 子程序已啟動，但初始化遭拒」。沒有放寬沙箱或繞過權限。生成仍未通過真實驗收。

產品是 Mac 上執行的本機 Web App（本機資料庫、後端、瀏覽器介面）。使用者後續接受網頁介面，因此已新增可雙擊的 `懷特先生.app` 啟動器，而非改寫成原生介面；最新功能與啟動驗收以 [CURRENT-STATUS](CURRENT-STATUS.md) 為準。AI 仍需網路，Mac 休眠時不能保證排程準時執行。
