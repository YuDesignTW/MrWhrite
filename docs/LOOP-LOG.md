## 明確保留的限制／後續工作

- 真實 Meta 權限、應用審查、回呼地址與 API 欄位尚待驗證；目前人工貼回官方 callback URL，不宣稱完整公開回呼服務已部署。
- IG adapter 為選用付費供應商，尚未決定預算或證實覆蓋；現有憑證為空時只保存待驗證來源。
- Threads 單篇解析暫在帳號前 100 篇可讀內容中比對；更早的單篇可能不可讀。跨平台媒體顯示目前只提供原文入口，未做縮圖呈現。
- 權杖續期目前由使用者按鈕觸發，不是無人值守自動續期。
- 當遠端發布結果不明時，查核可記錄容器狀態；若缺遠端貼文 ID，保持 unknown，不自動判定成功或開放重送。
- 目前限制來源數、每日時段與每次回傳筆數；沒有供應商帳單自動對帳／金額熔斷，付費啟用前須設定供應商端上限。
- 原 v0.1 的真實 Codex、隔離、Drive、IME／PWA 未驗收項目仍保留，不因本輪測試通過自動消除。
- 下一輪先在能執行本機服務與瀏覽器的環境完成 AC-18，再配置真實來源與官方授權；不擴張到階段 2～5。
